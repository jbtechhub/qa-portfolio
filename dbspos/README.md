# DBSPOS QA Testing Project

Manual and API testing project for the DBSPOS inventory and point-of-sale web application.

## Project Overview

DBSPOS is an inventory and point-of-sale system developed for small businesses.

The system includes product management, inventory, sales, expenses, debts, authentication, barcode scanning, and other business functions.

## Testing Scope

* Product management
* Product creation and validation
* Inventory data
* API testing
* Database verification
* Frontend and backend behavior comparison
* Authentication

## Testing Types

* Manual Functional Testing
* Negative Testing
* API Testing
* Data Validation
* Database Verification
* Exploratory Testing

## Tools Used

* Postman
* PostgreSQL
* Chrome DevTools
* GitHub

## Environment

Testing was performed on the installed/release version of DBSPOS as well as the development version when specifically identified.

## Testing Approach

Testing focuses on verifying system requirements, validating expected and unexpected inputs, checking API behavior, and verifying that data is correctly stored.

## Bug Reports

Confirmed defects found during testing are documented in the `bug-reports` folder with reproduction steps, expected and actual results, impact, and evidence.
