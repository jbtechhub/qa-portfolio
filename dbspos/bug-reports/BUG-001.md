# BUG-001: Product Creation API Accepts Selling Price Lower Than Buying Price

**Environment:** Installed DBSPOS / Release Version
**Testing Type:** API Testing
**Tool:** Postman
**Severity:** Medium
**Priority:** Medium
**Status:** Open

## Precondition

User is authenticated and the Product Creation API is accessible.

## Test Data

* Product Name: Release API Price Test
* Buy Price: ₱300
* Sell Price: ₱250
* Stock: 5

## Steps to Reproduce

1. Authenticate with the installed DBSPOS API.
2. Send a `POST` request to `/products`.
3. Enter `300` as the buy price.
4. Enter `250` as the sell price.
5. Enter `5` as the stock.
6. Send the request.

## Expected Result

The API should reject the request because the selling price is lower than the buying price.

The product should not be created.

## Actual Result

The API accepts the request and successfully creates the product.

The API response returns a newly created product with:

* Buy Price: ₱300
* Sell Price: ₱250
* Stock: 5

## Frontend Comparison

When the same invalid pricing is entered through the DBSPOS frontend, the system correctly rejects the input and displays:

**"Selling price cannot be lower than buying price."**

However, the same business rule is not enforced when the API is called directly.

## Impact

Invalid product pricing can be created by bypassing the frontend validation and sending the request directly to the API.
