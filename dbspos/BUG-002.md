# BUG-002: Product Creation API Accepts Duplicate Product Names

**Environment:** Installed DBSPOS / Release Version
**Testing Type:** API Testing
**Tool:** Postman
**Severity:** Medium
**Priority:** Medium
**Status:** Open

## Description

The Product Creation API allows a product to be created using a product name that already exists in the system.

The frontend correctly prevents duplicate product names by displaying **"Product already exists"**, but the API does not enforce the same validation rule.

## Preconditions

* User is authenticated.
* DBSPOS is installed and running.
* An existing product named **Shampoo 15ml** is already in the system.

## Steps to Reproduce

1. Send a `POST` request to the Product Creation API.
2. Use an existing product name: `Shampoo 15ml`.
3. Provide valid buy price, sell price, and stock.
4. Submit the request.

## Test Data

```json
{
  "name": "Shampoo 15ml",
  "buy_price": 8,
  "sell_price": 10,
  "stock": 5
}
```

## Expected Result

The API should reject the request because the product name already exists.

No duplicate product should be created.

## Actual Result

The API accepted the request and created a new product with the same name.

The API returned a successful response with a new product ID.

## Impact

Duplicate product records can be created through direct API requests even though the frontend prevents duplicate product names.

This can result in duplicate products appearing in the inventory and may cause confusion when managing or selling products.

## Frontend Comparison

When attempting to create the same product through the frontend, the system correctly displays:

**"Product already exists"**

This indicates that the duplicate-name validation exists in the frontend but is not enforced by the API.

## Result

**FAIL**
